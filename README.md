# Calculadora de factorial

Ejercicio de lógica de programación con **HTML y JavaScript**. Una interfaz recibe un número y calcula su factorial mediante un ciclo `for`.

## Probar el ejercicio

Clona el repositorio y abre `index.html` en tu navegador. También puedes servir la carpeta con Live Server en VS Code. No requiere compilación ni un backend.

Ejemplo: introducir `5` y pulsar el botón de cálculo muestra `120`.

## Archivos

- `index.html`: interfaz del ejercicio.
- `script.js`: lectura del valor, ciclo de cálculo y presentación del resultado.

## Alcance y aspectos por mejorar

Es una práctica, no una calculadora de precisión arbitraria. La implementación utiliza `Number` de JavaScript y debe reforzar la validación de valores vacíos, negativos y decimales, así como el límite de precisión para números grandes.
